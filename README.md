## 🛠️ Core Concepts Covered

* **Core JavaScript (ES6+):** Arrow functions, template literals, destructuring, higher-order methods (`map`, `filter`, `reduce`).
* **DOM Manipulation:** `querySelector`, `addEventListener`, dynamic node insertion/removal, classes manipulation.
* **Storage APIs:** Persistent client-side caching using `localStorage` and temporary session caching using `sessionStorage`.
* **Form Validation & Regex:** Pattern matching for email, phone numbers, vehicle license plates, passwords, and custom input sanitization.
* **UI/UX Design:** Modern CSS gradients, flexbox, grid, glassmorphism card layouts, and responsive design for desktop and mobile.

## 🚀 Getting Started & Local Preview

### Prerequisites
You only need a modern web browser (Google Chrome, Firefox, Edge, etc.) and a code editor like Visual Studio Code.

### Running Any Practical
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Salimansari369/javascript.git
   cd javascript
   ```
2. **Open any practical in your browser:**
   * Navigate to any folder (e.g. `9 - Theme preferences and schedule planner/Theme preferences`).
   * Double-click `index.html` to open it directly in your browser.
   * Or open the folder in **VS Code** and click **"Go Live"** using the **Live Server** extension.
